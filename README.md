# Ad Backend API

A production-ready Node.js/Express backend service integrated with MongoDB Atlas and automated email notification services.

## 🚀 Live Demo
- **Live API Base URL:** `https://ad-backend-api.onrender.com`

## ✨ Features
- **Database Integration**: Connected to MongoDB Atlas for persistent data handling.
- **Email Notifications**: Automated email delivery powered by Nodemailer with Google OAuth2.
- **RESTful Endpoints**: Clean API routes for transaction management and core business logic.
- **Environment Security**: Secure handling of production secrets and CORS policies.

## 🛠 Tech Stack
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB Atlas (Mongoose)
- **Authentication / Mail**: Google OAuth2, Nodemailer
- **Deployment**: Render
